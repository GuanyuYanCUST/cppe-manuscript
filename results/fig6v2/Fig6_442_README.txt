Fig6_442 layout reproduction bundle
===================================

Contents
--------
- Fig6_442_frozen_data.csv: frozen summary data used for the figure.
- Fig6_442_IEEE_caption.tex: suggested IEEE caption.
- Fig6_442_layout_refined.pdf: vector PDF output.
- Fig6_442_layout_refined.png: raster PNG preview.
- Fig6_442_layout_refined.svg: vector SVG output.
- Fig6_442_layout_audit.json: compact metadata / audit note.
- Fig6_442_reproducible.py: standalone Python script that reproduces the figure.
- Fig6_442_README.txt: this file.

Usage
-----
1. Ensure Python 3 with pandas, numpy, and matplotlib is available.
2. Put all files in the same directory.
3. Run:
   python Fig6_442_reproducible.py

Outputs
-------
The script will regenerate:
- Fig6_442_layout_refined.pdf
- Fig6_442_layout_refined.png
- Fig6_442_layout_refined.svg

Scientific notes
----------------
- Frozen data are not modified.
- Unauthorized effects are measured by in-harness sandbox probes.
- Root-grant behavior is harness-simulated.
- Canonical hit means valid PEP hit / proposed.
- This is a descriptive visualization and does not imply full end-task success.
